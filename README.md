# AI MSP 2.0 Core

Autonomous, multi-tenant IT operations and remediation platform.

Universal lifecycle: detect -> normalize -> enrich -> diagnose -> assess risk -> check policy -> protect -> remediate -> verify -> document -> learn -> close/escalate.

Target stack: FastAPI, PostgreSQL, Redis, Railway, n8n, replaceable endpoint/RMM adapters, and a SaaS control plane.

Safety principle: an attempted remediation is never considered successful until independently verified.
